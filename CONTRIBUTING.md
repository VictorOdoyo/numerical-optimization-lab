# Contributing

Use Node 24, npm ci, npm test, npm run benchmark, npm run format:check and npm run package:check. Install Chromium before npm run test:browser. Install validation/requirements.txt in a separate Python environment for independent references.

Algorithm changes should include an independent oracle, certificate or mathematical invariant. Preserve truthful budget/stagnation statuses, finite result handling, deterministic replay and declared cost accounting. Keep browser code separate from Node-only serving. Update method assumptions and result contracts with behavioral changes. Never pad history with empty commits or generated runtime artifacts.
